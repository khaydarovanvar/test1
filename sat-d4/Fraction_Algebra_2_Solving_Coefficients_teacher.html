Fraction Algebra 2 — Solving Coefficients

Worked method · diagrams for every step · Desmos lines · three new questions | Teacher copy — with solutions · Grade 11 · Ellipse International School

1What the question is really asking

the two sides are the same fraction, so the numerators must match once the denominators do

Nothing here is solved for x. The equation holds for every x, so it is an identity: add the right-hand side into a single fraction, make its denominator the one you were given, and the numerator that appears is ax³ + bx² + cx + d.

2Reading the coefficients off, instead of expanding

P(0) = d | P(1) = a + b + c + d | so a + b + c = P(1) − P(0)

Once you know the numerator is some cubic P(x), you never have to expand it. Substituting x = 1 adds every coefficient up; substituting x = 0 leaves only d. Subtract, and the d cancels. This is the whole reason the question asks for a + b + c and not for b alone.

3The one thing that can go wrong

the shortcut needs x = 0 and x = 1 to be ordinary values, not poles

You are substituting into the fraction form, which is undefined wherever a denominator is zero. In this question the poles are x = 3 and x = −3, so 0 and 1 are both fine. If a question put a pole at x = 1, Desmos would return undefined and you would have to expand the numerator first, or fit it instead.

4The worked question

(ax³ + bx² + cx + d) ÷ ((x² − 9)(x + 2)) = 5/(x + 3) + 6x/(x − 3) — find a + b + c

Solution. Add the right-hand side, then supply the factor the denominator is still missing.
Working.

5(x − 3) + 6x(x + 3) = 5x − 15 + 6x² + 18x = 6x² + 23x − 15, all over x² − 9.

(x² − 9)(x + 2) needs one more factor of (x + 2), so multiply top and bottom by it.

(6x² + 23x − 15)(x + 2) = 6x³ + 35x² + 31x − 30.

a = 6, b = 35, c = 31 and d = −30, so a + b + c = 72.

In Desmos (five lines, and two of them are only the check)

Two lines solve it. The first names the numerator; the second reads the answer out of it. The third and fourth are the check — define the cubic you found and see that it draws the same curve.

Three more of the same kind (hardest last)

Same shape every time: a cubic over a disguised product of three linear factors, equal to two fractions whose denominators are two of those three. Find the factor the sum is missing, and the numerator falls out.

#LevelQuestionAnswerSolution
Q1Hard
(ax³ + bx² + cx + d) ÷ ((x² − 16)(x + 1)) = 3/(x + 4) + 2x/(x − 4). What is the value of a + b + c?
14

Add the right-hand side over x² − 16: 3(x − 4) + 2x(x + 4) = 2x² + 11x − 12.

The given denominator carries an extra (x + 1), so the numerator is (2x² + 11x − 12)(x + 1) = 2x³ + 13x² − x − 12.

a + b + c = 2 + 13 − 1 = 14. In Desmos: P(1) − P(0) = 2 − (−12) = 14.

Q2Hard
(ax³ + bx² + cx + d) ÷ ((x² − 25)(x − 2)) = 4/(x − 5) + 7x/(x + 5). What is the value of a + b + c?
44

The fractions are written the other way round, so take care which one is multiplied by which: 4(x + 5) + 7x(x − 5) = 7x² − 31x + 20.

The missing factor is (x − 2), giving (7x² − 31x + 20)(x − 2) = 7x³ − 45x² + 82x − 40.

a + b + c = 7 − 45 + 82 = 44. In Desmos: P(1) − P(0) = 4 − (−40) = 44.

Q3Very
hard
(ax³ + bx² + cx + d) ÷ ((x² − 1)(x − 4)) = 7/(x + 1) + 2x/(x − 1). What is the value of a + b + c?
−40

Over x² − 1: 7(x − 1) + 2x(x + 1) = 2x² + 9x − 7, and the missing factor is (x − 4).

(2x² + 9x − 7)(x − 4) = 2x³ + x² − 43x + 28, so a + b + c = 2 + 1 − 43 = −40.

The shortcut breaks here. The poles are x = 1 and x = −1, so P(1) is undefined in Desmos. Either expand as above, or fit the cubic through five safe points such as x = 0, 2, 3, 5, 6.

The one habit to build. Factorise the denominator you are given before you touch the fractions on the right. The answer to every question of this kind is the factor that is in one list and not the other.

Every numerator here was expanded in exact arithmetic and checked against the original identity at 400 random values of x; a + b + c was then confirmed a second way as P(1) − P(0).
