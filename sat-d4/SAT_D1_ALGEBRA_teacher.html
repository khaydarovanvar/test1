SAT Math 1.1 — Linear Equations in One Variable

Explanations with worked examples · diagrams for every rule · Desmos questions | Teacher copy — with solutions · Grade 11 · Ellipse International School

1Multi-step equations

undo the operations in reverse order | whatever you do to one side, do to the other

Work from the outside in: deal with addition and subtraction before multiplication and division. Substituting your answer back is a ten-second check that catches almost every slip.

Example 1. Solve 5(x − 2) = 30.
Solution.

Divide by 5: x − 2 = 6.

x = 8. Check: 5(6) = 30.

Example 2. Solve 4x + 7 = 2x − 5.
Solution.

Collect x on one side: 2x = −12.

x = −6.

Example 3. Solve 3(2x + 1) − 4 = 11.
Solution.

6x + 3 − 4 = 11, so 6x = 12.

x = 2.

2Clearing fractions and decimals

multiply every term by the common denominator

Fractions make arithmetic slow and errors likely. Multiply the whole equation through by the lowest common denominator first, and the problem becomes an ordinary one.

Example 1. Solve x/3 + x/4 = 14.
Solution.

Multiply everything by 12: 4x + 3x = 168.

7x = 168, so x = 24.

Example 2. Solve (x + 2)/5 = 3.
Solution.

Multiply by 5: x + 2 = 15.

x = 13.

Example 3. Solve 0.4x + 1.2 = 3.6.
Solution.

Multiply by 10 to clear decimals: 4x + 12 = 36.

4x = 24, so x = 6.

3Translating a sentence

name the unknown | write one equation | answer the question that was asked

Most SAT algebra is a sentence in disguise. ‘A fixed charge plus so much each’ is always b + mx. Write the equation before touching any arithmetic.

Example 1. A bakery charges $2 for a box plus $3 per muffin. A customer pays $23. How many muffins?
Solution.

2 + 3m = 23, so 3m = 21.

m = 7 muffins.

Example 2. A fabric shop charges $4.50 per metre plus a $2 cutting fee. A customer pays $29. How many metres?
Solution.

4.5x + 2 = 29, so 4.5x = 27.

x = 6 metres.

Example 3. Three more than twice a number is 17. Find the number.
Solution.

2n + 3 = 17, so 2n = 14.

n = 7.

4Literal equations

treat the other letters as numbers and isolate the one you want

Rearranging a formula uses exactly the same moves as solving for x. If the target letter appears twice, gather those terms together and factor it out.

Example 1. Solve A = ½bh for h.
Solution.

Multiply by 2: 2A = bh.

h = 2A/b.

Example 2. Solve y = mx + b for x.
Solution.

y − b = mx.

x = (y − b)/m.

Example 3. Solve ax = bx + c for x, where a ≠ b.
Solution.

x appears twice, so gather and factor: ax − bx = c, giving x(a − b) = c.

x = c/(a − b).

5No solution or infinitely many

variables cancel and the statement is false → no solution | true → infinitely many

Simplify both sides fully. If the x terms vanish, look at what is left: 5 = 7 is false, so nothing works; 5 = 5 is true, so everything works. For ax + b = cx + d this means a = c with b ≠ d, or a = c with b = d.

Example 1. Solve 2(x + 3) = 2x + 7.
Solution.

2x + 6 = 2x + 7 gives 6 = 7, which is false.

No solution.

Example 2. Solve 3(x − 1) = 3x − 3.
Solution.

3x − 3 = 3x − 3 gives 0 = 0, which is always true.

Infinitely many solutions.

Example 3. For what k does kx + 5 = 4x + 5 have infinitely many solutions?
Solution.

The sides must match exactly.

k = 4.

6Checking and interpreting

substitute back | and make sure the answer is the quantity asked for

Two different habits, both worth marks. Substituting catches arithmetic errors. Re-reading the question catches the trap where you solve for x but the question wanted 2x, or the price rather than the quantity.

Example 1. A student solves 4x + 7 = 2x − 5 and gets x = 6. Check it.
Solution.

Left: 31. Right: 7. They differ, so x = 6 is wrong; the correct answer is −6.

Example 2. If 3x − 4 = 11, what is the value of 6x?
Solution.

3x = 15, so x = 5.

6x = 30, not 5 — read what was asked.

Example 3. If 2n + 3 = 17, what is n + 1?
Solution.

n = 7, so n + 1 = 8.

SAT Math 1.2 — Linear Functions

Explanations with worked examples · diagrams for every rule · Desmos questions | Teacher copy — with solutions · Grade 11 · Ellipse International School

1Slope as a rate of change

m = (y₂ − y₁)/(x₂ − x₁) = rise over run

Slope is how much y changes for a one-unit rise in x. In a real context it always carries units: dollars per kilometre, degrees per hour. Keep the two points in the same order top and bottom.

Example 1. Find the slope through (1, 1.75) and (5, 4.75).
Solution.

(4.75 − 1.75)/(5 − 1) = 3/4.

m = 0.75.

Example 2. A tailor charges $19 for 2 m and $40 for 5 m. Find the rate per metre.
Solution.

(40 − 19)/(5 − 2) = 21/3 = $7 per metre.

Example 3. What is the slope of the line through (2, 7) and (6, −1)?
Solution.

(−1 − 7)/(6 − 2) = −8/4 = −2.

2y = mx + b in context

b is the starting or fixed amount | m is the amount per unit

Interpretation questions are worth easy marks if you name the units. In C = 2.50 + 1.75d, the 2.50 is dollars and the 1.75 is dollars per kilometre — the ‘per’ is what makes it a rate.

Example 1. C = 2.50 + 1.75d gives a taxi fare for d kilometres. What does 1.75 mean?
Solution.

The cost per kilometre, in dollars.

Example 2. What does 2.50 mean in that model?
Solution.

The fixed starting fare before any distance is travelled.

Example 3. P(n) = 2.5n − 40 gives daily profit for n melons. What does 2.5 mean?
Solution.

The increase in profit for each extra melon sold, in dollars.

3Writing a line from information

from two points: find m, then use y = mx + b with one point to get b

Three routes to the same line: two points, a point and a slope, or a table. Find the slope first in every case, then pin down b by substituting a known point.

Example 1. A tailor charges $19 for 2 m and $40 for 5 m. Write the model.
Solution.

m = 7, and 19 = 7(2) + b gives b = 5.

C = 7x + 5.

Example 2. For that model, what is the charge for 8 metres?
Solution.

7(8) + 5 = $61.

Example 3. Write the equation of the line with slope −3 through (2, 1).
Solution.

1 = −3(2) + b gives b = 7.

y = −3x + 7.

4Intercepts and what they mean

y-intercept: set x = 0 | x-intercept: set y = 0

In context the y-intercept is the starting value and the x-intercept is when the quantity reaches zero — the break-even point, or when a tank empties.

Example 1. Find both intercepts of 2x + 5y = 20.
Solution.

x = 0 gives y = 4; y = 0 gives x = 10.

(0, 4) and (10, 0).

Example 2. A tank model is V = 200 − 8t litres. When is it empty?
Solution.

200 − 8t = 0, so t = 25 minutes.

Example 3. What does the 200 represent?
Solution.

The starting volume, in litres, at t = 0.

5Function notation

f(3) means substitute 3 | f(x) = 3 means solve for x

The notation is compact but precise. Reading f(a) = b off a graph means the point (a, b) lies on it. Evaluating and solving are opposite directions, and the SAT tests both.

Example 1. f(x) = 3x − 5. Find f(4).
Solution.

3(4) − 5 = 7.

Example 2. For that f, solve f(x) = 16.
Solution.

3x − 5 = 16, so 3x = 21.

x = 7.

Example 3. The graph of f passes through (2, 9). Write that in function notation.
Solution.

f(2) = 9.

6Linear models and tables

a constant difference in a table means the model is linear

Check the y-differences for equal steps. Once you know it is linear, the common difference is the slope and the value at x = 0 is b.

Example 1. A table gives y = 5, 8, 11, 14 for x = 0, 1, 2, 3. Write the model.
Solution.

Differences are all 3, and y = 5 at x = 0.

y = 3x + 5.

Example 2. A table gives y = 20, 17, 14 for x = 1, 2, 3. Write the model.
Solution.

Difference −3, and at x = 1, y = 20, so b = 23.

y = −3x + 23.

Example 3. Is y = 2, 4, 8, 16 linear?
Solution.

Differences 2, 4, 8 are not constant.

No — it is exponential, with ratio 2.

SAT Math 1.3 — Linear Equations in Two Variables

Explanations with worked examples · diagrams for every rule · Desmos questions | Teacher copy — with solutions · Grade 11 · Ellipse International School

1Graphing a line

plot both intercepts and join them | or start at b and step by the slope

From standard form, the intercepts are the fastest two points: set x = 0, then set y = 0. From slope-intercept form, plot b on the y-axis and step rise over run.

Example 1. Find both intercepts of 3x + 4y = 12.
Solution.

x = 0 gives y = 3; y = 0 gives x = 4.

(0, 3) and (4, 0).

Example 2. Describe how to graph y = 2x − 3 without a table.
Solution.

Start at (0, −3), then go up 2 and right 1 to reach (1, −1).

Example 3. Find the x-intercept of y = −5x + 20.
Solution.

0 = −5x + 20, so x = 4.

2Is this point on the line?

substitute both coordinates and see whether the equation holds

There is nothing clever here, and that is the point: a question asking which point lies on a line is answered by testing options until one works.

Example 1. Does (3, 5) lie on y = 2x − 1?
Solution.

2(3) − 1 = 5, which matches.

Yes.

Example 2. Does (2, 9) lie on 4x + y = 16?
Solution.

8 + 9 = 17, not 16.

No.

Example 3. The point (k, 7) lies on y = 3x + 1. Find k.
Solution.

7 = 3k + 1, so 3k = 6.

k = 2.

3The same line in different clothes

slope-intercept y = mx + b | standard Ax + By = C | point-slope y − y₁ = m(x − x₁)

Two equations describe the same line when one is a multiple of the other. Rearranging to y = mx + b is the quickest way to compare.

Example 1. Write 2x + 3y = 12 in slope-intercept form.
Solution.

3y = −2x + 12.

y = −(2/3)x + 4.

Example 2. Are 2x + 3y = 12 and 4x + 6y = 24 the same line?
Solution.

The second is exactly twice the first.

Yes — one line, written two ways.

Example 3. Write the line through (2, 5) with slope 3 in point-slope form.
Solution.

y − 5 = 3(x − 2), which rearranges to y = 3x − 1.

4Parallel and perpendicular

parallel → same slope | perpendicular → slopes multiply to −1

Rearrange both equations into y = mx + b before comparing. To get a perpendicular slope, flip the fraction and change the sign.

Example 1. Is y = 3x + 1 parallel to 6x − 2y = 8?
Solution.

The second gives y = 3x − 4, the same slope.

Yes, parallel.

Example 2. Find the slope perpendicular to y = −(2/5)x + 1.
Solution.

Flip and negate.

5/2.

Example 3. Write the line through (0, −1) perpendicular to y = 4x.
Solution.

Perpendicular slope −1/4.

y = −(1/4)x − 1.

5Horizontal and vertical lines

y = c is horizontal, slope 0 | x = c is vertical, slope undefined

A horizontal line has zero slope because nothing rises. A vertical line has no slope at all, because the run is zero and you cannot divide by it — ‘zero slope’ and ‘undefined slope’ are different things.

Example 1. What is the slope of y = 7?
Solution.

0 — it is horizontal.

Example 2. What is the slope of x = −3?
Solution.

Undefined — it is vertical, and the run is zero.

Example 3. Write the line through (4, 9) that is parallel to the x-axis.
Solution.

Parallel to the x-axis means horizontal.

y = 9.

6Reading a line off a graph

find b where it crosses the y-axis, then count rise over run between two grid points

Pick two points where the line passes exactly through grid intersections, or the slope you count will be wrong. Then read b directly.

Example 1. A line crosses the y-axis at 1 and passes through (4, 4). Find its equation.
Solution.

m = (4 − 1)/4 = 3/4.

y = (3/4)x + 1.

Example 2. A line falls 2 for every 1 across and passes through (0, 5). Find its equation.
Solution.

y = −2x + 5.

Example 3. A graph shows a line through (0, 1) and (5, 4.75). Find its slope.
Solution.

(4.75 − 1)/5 = 0.75.

SAT Math 1.4 — Systems of Linear Equations

Explanations with worked examples · diagrams for every rule · Desmos questions | Teacher copy — with solutions · Grade 11 · Ellipse International School

1Elimination

line the equations up and add or subtract to kill one variable

Elimination is usually faster than substitution on the SAT, because the coefficients are chosen to cooperate. If they do not match, multiply one equation through first.

Example 1. Solve 2x + y = 11 and x − y = 4.
Solution.

Adding kills y: 3x = 15, so x = 5.

Then y = 1, giving (5, 1).

Example 2. Solve 3a + 2p = 8 and a + 2p = 6.
Solution.

Subtracting kills p: 2a = 2, so a = 1.

Then p = 2.5, giving a = 1, p = 2.5.

Example 3. Solve 3x + 2y = 57 and x + 4y = 39.
Solution.

Multiply the second by 3: 3x + 12y = 117. Subtract: 10y = 60, so y = 6.

Then x = 15, giving (15, 6).

2Substitution

when one variable is already alone, put that expression into the other equation

Substitution is the natural choice when an equation reads y = something. Replace, solve for the remaining variable, then go back for the other one.

Example 1. Solve y = 2x + 3 and 3x + y = 13.
Solution.

3x + (2x + 3) = 13 gives 5x = 10, so x = 2.

Then y = 7: (2, 7).

Example 2. Solve x = y + 4 and 2x + 3y = 23.
Solution.

2(y + 4) + 3y = 23 gives 5y = 15, so y = 3.

Then x = 7: (7, 3).

Example 3. Why finish by finding the second variable?
Solution.

A system’s solution is a point. Stopping at x answers only half the question — though do check whether the question wanted only one of them.

3One, none, or infinitely many

different slopes → one | same slope, different intercept → none | identical → infinitely many

Two lines either cross once, run parallel forever, or sit on top of each other. For a₁x + b₁y = c₁ and a₂x + b₂y = c₂, compare the ratios a₁/a₂, b₁/b₂ and c₁/c₂.

Example 1. How many solutions does 3x + 5y = 21 and 6x + 10y = 42 have?
Solution.

The second is exactly twice the first.

Infinitely many — one line.

Example 2. How many solutions does 3x + 5y = 21 and 6x + 10y = 35 have?
Solution.

Same slope, different constant: parallel.

None.

Example 3. How many does 3x + 5y = 21 and 2x − y = 4 have?
Solution.

The slopes differ.

Exactly one.

4Finding the parameter

no solution → match the coefficients but not the constants | infinitely many → match everything

These questions give you a letter in one coefficient and ask you to force a case. Scale one equation until the x and y parts line up, then compare the constants.

Example 1. For what k does 3x + 5y = 21 and kx + 10y = 35 have no solution?
Solution.

Doubling the first gives 6x + 10y = 42, so k = 6, and 42 ≠ 35 confirms no solution.

Example 2. For what k does 2x + 6y = 10 and kx + 9y = 15 have infinitely many solutions?
Solution.

Multiplying the first by 1.5 gives 3x + 9y = 15.

k = 3.

Example 3. For what value of k does 3x + ky = 8 and 6x + 10y = 9 have no solution?
Solution.

Doubling the first gives 6x + 2ky = 16, so 2k = 10.

k = 5.

5Two-constraint word problems

one equation for the count, one for the value

Tickets, coins, mixtures and two-rate problems all share this shape: how many things, and how much they are worth. Define both variables before writing anything.

Example 1. Adult tickets cost $12 and student $7. 45 tickets sold for $440. How many adult tickets?
Solution.

a + s = 45 and 12a + 7s = 440.

Substituting: 12a + 7(45 − a) = 440 gives 5a = 125, so a = 25.

Example 2. 3 apples and 2 pears cost $8.00; 1 apple and 2 pears cost $6.00. Find the price of a pear.
Solution.

Subtracting: 2 apples cost $2, so an apple is $1.

Then 2 pears cost $5: a pear is $2.50.

Example 3. 3 crates and 2 baskets cost 57; 1 crate and 4 baskets cost 39. Find the crate price.
Solution.

Multiply the second by 3 and subtract: 10 baskets = 60, so a basket is 6.

A crate is (57 − 12)/3 = 15.

6Interpreting the solution

the solution is the point where both conditions hold at once

In context the intersection is the break-even point, the moment two plans cost the same, or the mix that satisfies both requirements. Check your answer makes sense: you cannot sell 2.5 tickets.

Example 1. Two plans cost C = 30 + 4n and C = 50 + 2n. What does their intersection mean?
Solution.

The number of items at which both plans cost the same: n = 10, at $70.

Example 2. A system gives a = 25 and s = 20 for tickets. Check it against 45 tickets for $440.
Solution.

25 + 20 = 45 ✓ and 12(25) + 7(20) = 300 + 140 = 440 ✓.

Both hold.

Example 3. A ticket system solves to a = 22.5. What does that tell you?
Solution.

That something is wrong — you cannot sell half a ticket. Recheck the setup.

SAT Math 1.5 — Linear Inequalities

Explanations with worked examples · diagrams for every rule · Desmos questions | Teacher copy — with solutions · Grade 11 · Ellipse International School

1Solving an inequality

solve exactly as for an equation — but flip the sign when you multiply or divide by a negative

Every move is the same as for an equation except one. Multiplying or dividing both sides by a negative number reverses the direction, and forgetting that is the classic error.

Example 1. Solve 5 − 2x > 17.
Solution.

−2x > 12, and dividing by −2 flips the sign.

x < −6.

Example 2. Solve 3x + 4 ≤ 19.
Solution.

3x ≤ 15.

x ≤ 5. No flip — we divided by a positive.

Example 3. Solve −x/3 ≥ 2.
Solution.

Multiply by −3 and flip.

x ≤ −6.

2Translating the words

‘at least’ → ≥ | ‘at most’ / ‘no more than’ → ≤ | ‘more than’ → >

The wording decides whether the boundary counts. ‘Greater than $50’ excludes $50 exactly, so the least whole number of sales is one past the boundary.

Example 1. A vendor spends $75 and sells at $2.50 a cup. How many cups for profit over $50?
Solution.

2.5n − 75 > 50 gives n > 50.

The least whole number is 51, not 50.

Example 2. A lift holds at most 600 kg. Write this as an inequality for the load L.
Solution.

L ≤ 600 — 600 itself is allowed.

Example 3. A club needs at least 20 members. Write it for membership m.
Solution.

m ≥ 20.

3Interpreting a constant in context

ask what the units of each side are

In 3a + 7b ≤ 84, the left side is a cost in talens, so 84 is the most that can be spent — not a count of items. Checking units settles these questions immediately.

Example 1. A stallholder buys a bags at 3 each and b jars at 7 each, with 3a + 7b ≤ 84. What is 84?
Solution.

Both sides are costs, so 84 is the maximum amount that can be spent.

Example 2. In 5x + 2y ≥ 40 where x is hours worked, what does 40 represent?
Solution.

The minimum total the quantities must reach.

Example 3. Why is ‘the total number of items’ a wrong reading of 84?
Solution.

The coefficients 3 and 7 are prices, so the product is money, not a count. The units do not match.

4Graphing an inequality

solid line for ≤ or ≥ | dashed for < or > | test a point to decide which side

Draw the boundary line first, then pick any point not on it — (0, 0) is easiest — and see whether it satisfies the inequality. If it does, shade its side.

Example 1. Describe the graph of y ≤ −x + 4.
Solution.

A solid line through (0, 4) and (4, 0), with the region below shaded.

Example 2. Does (1, 1) satisfy y ≤ −x + 4?
Solution.

1 ≤ 3.

Yes, so it is in the shaded region.

Example 3. Does (4, 4) satisfy it?
Solution.

4 ≤ 0 is false.

No — it lies above the line.

5Compound inequalities

‘and’ → the overlap | ‘or’ → either region

Solve a three-part inequality by doing the same thing to all three parts at once. Keep the variable in the middle and remember that flipping applies to the whole chain.

Example 1. Solve 3 < 2x + 1 < 11.
Solution.

Subtract 1 throughout: 2 < 2x < 10.

1 < x < 5.

Example 2. Solve −4 ≤ 5 − 3x ≤ 8.
Solution.

Subtract 5: −9 ≤ −3x ≤ 3. Divide by −3 and flip both signs.

−1 ≤ x ≤ 3.

Example 3. How many integers satisfy 1 < x < 5?
Solution.

x = 2, 3, 4.

Three.

6Systems of inequalities

the solution is the region satisfying every inequality at once

Shade each inequality and look for the overlap. To test whether a point is a solution, check it in every inequality — it only takes one failure to rule a point out.

Example 1. Does (2, 1) satisfy y ≤ −x + 4 and y ≥ 0?
Solution.

1 ≤ 2 ✓ and 1 ≥ 0 ✓.

Yes, both hold.

Example 2. Does (5, 1) satisfy that system?
Solution.

1 ≤ −1 is false.

No — one failure is enough.

Example 3. A system is y > 2 and y < 1. What is the solution region?
Solution.

No value of y is both above 2 and below 1.

Empty — there is no solution.

SAT Math 1.6 — Absolute Value

Explanations with worked examples · diagrams for every rule · Desmos questions | Teacher copy — with solutions · Grade 11 · Ellipse International School

1What absolute value means

|a| is the distance from zero, so it is never negative

Distance has no direction, which is why |−7| = 7. An equation |x| = c with c negative has no solution at all, because no distance is negative.

Example 1. Evaluate |−7| + |3|.
Solution.

7 + 3 = 10.

Example 2. Solve |x| = 9.
Solution.

x is 9 away from zero in either direction.

x = 9 or −9.

Example 3. Solve |x| = −4.
Solution.

No solution — an absolute value can never be negative.

2Solving |ax + b| = c

split into two equations: ax + b = c and ax + b = −c

The bars hide a plus-or-minus. Write both cases before solving either, and check c is not negative first.

Example 1. Solve |2p − 9| = 5.
Solution.

2p − 9 = 5 gives p = 7; 2p − 9 = −5 gives p = 2.

p = 7 or 2, and their sum is 9.

Example 2. Solve |x + 3| = 8.
Solution.

x + 3 = 8 or x + 3 = −8.

x = 5 or −11.

Example 3. Solve |3x − 1| = 11.
Solution.

3x − 1 = 11 gives x = 4; 3x − 1 = −11 gives x = −10/3.

x = 4 or −10/3.

3Isolate the bars first

get |…| alone on one side before splitting

If something is added to or multiplying the absolute value, undo that first. Splitting too early produces two wrong equations instead of one right pair.

Example 1. Solve 2|x − 1| + 3 = 11.
Solution.

Isolate: 2|x − 1| = 8, so |x − 1| = 4.

x − 1 = ±4, giving x = 5 or −3.

Example 2. Solve |x + 2| − 5 = 0.
Solution.

|x + 2| = 5.

x = 3 or −7.

Example 3. Why not split 2|x − 1| + 3 = 11 straight away?
Solution.

The +3 and the 2 are outside the bars, so they apply to the whole distance. Splitting first would attach them to only one side and both answers would be wrong.

4Absolute value inequalities: the ‘and’ case

|x| < c means −c < x < c — one interval, between

Less than means close to zero, so the solution is a single band around the centre. Write it as a compound inequality and solve all three parts at once.

Example 1. Solve |x| < 6.
Solution.

−6 < x < 6.

Example 2. Solve |x − 3| ≤ 5.
Solution.

−5 ≤ x − 3 ≤ 5, so add 3 throughout.

−2 ≤ x ≤ 8.

Example 3. Solve |2x + 1| < 7.
Solution.

−7 < 2x + 1 < 7 gives −8 < 2x < 6.

−4 < x < 3.

5Absolute value inequalities: the ‘or’ case

|x| > c means x < −c or x > c — two separate pieces

Greater than means far from zero, so the solution splits into two rays with a gap in the middle. It can never be written as a single interval.

Example 1. Solve |x| > 4.
Solution.

x < −4 or x > 4.

Example 2. Solve |x − 2| ≥ 6.
Solution.

x − 2 ≥ 6 or x − 2 ≤ −6.

x ≥ 8 or x ≤ −4.

Example 3. A machine part must be within 0.4 mm of 25 mm. Write that as an inequality.
Solution.

|L − 25| ≤ 0.4, which means 24.6 ≤ L ≤ 25.4.

6The V-shaped graph

y = |x − h| + k is a V with vertex (h, k)

The graph folds upward at the vertex. A horizontal line cuts it twice above the vertex, once at the vertex, and not at all below — which is how the number of solutions is decided.

Example 1. Find the vertex of y = |x − 1|.
Solution.

(1, 0).

Example 2. How many solutions does |x − 1| = 3 have?
Solution.

The line y = 3 is above the vertex, so it cuts the V twice.

Two: x = 4 and x = −2.

Example 3. How many solutions does |x − 1| = 0 have?
Solution.

The line passes exactly through the vertex.

One: x = 1.

The price p, in talens, of a lantern satisfies |2p − 9| = 5. What is the sum of all possible values of p?
9

2p − 9 = 5 gives p = 7, and 2p − 9 = −5 gives p = 2.

x = 5 and x = −11

x = 5 and x = −3

Isolate first: 2|x − 1| = 8, so |x − 1| = 4.

Solve the inequality |x − 3| ≤ 5. Write your answer as a compound inequality.
−2 ≤ x ≤ 8

Less than means a single band: −5 ≤ x − 3 ≤ 5.

Adding 3 throughout gives −2 ≤ x ≤ 8.

Solve the inequality |x − 2| ≥ 6. Describe all values of x.
x ≤ −4 or x ≥ 8

Greater than means two separate pieces: x − 2 ≥ 6 or x − 2 ≤ −6.

x ≥ 8 or x ≤ −4. This cannot be written as one interval.

|L − 25| ≤ 0.4

‘Within 0.4 of 25’ is a distance statement.

|L − 25| ≤ 0.4, which unpacks to 24.6 ≤ L ≤ 25.4.

A thermostat keeps a room within 1.5°C of 21°C. Write an absolute-value inequality for the temperature T, and state the range of acceptable temperatures.
|T − 21| ≤ 1.5, so 19.5 ≤ T ≤ 22.5
