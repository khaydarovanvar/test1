# Exams

Papers written to the school format: 40 minutes, Calibri 12, 1.15 line spacing,
Normal margins (2.54 cm), left-aligned with centred titles, numbered questions,
bold section headings, and the difficulty split 40 % easy / 40 % medium / 20 % hard.

| File | What it is |
|---|---|
| `11AG-MATH-FINAL.docx` | **the paper to submit** — the school cover page plus 20 questions, 100 marks |
| `11AG-MATH-FINAL.pdf` | the same, as PDF |
| `11AG-MATH-FINAL-MARKING-SCHEME.docx` / `.pdf` | teacher copy with every answer — not for distribution |

The file name follows *Sinf + Guruh – Fan – Imtihon turi*: `11AG-MATH-FINAL`.

## The cover page

`Exam Cover Page (2).docx` from the `mathematics` repository is used as it is.
Only the four values a teacher fills in were changed — Subject, Grade, Name of
the Teacher and Date. The logo, the table, the instructions, the score line and
the `Final Exam` and `40 minutes` entries are untouched, and a byte comparison
against the original confirms no other part of the file differs.
