# Stemco

## ⚽ ALI FC — football-themed learning app

An interactive app that teaches **English, reading, writing and mathematics** to
an Uzbek-speaking beginner by turning the whole curriculum into a football
career — training sessions, matches, goals and trophies.

**Open [`app/ali-fc-offline.html`](app/ali-fc-offline.html)** — a single
self-contained file, no install and no internet needed.

See [`app/README.md`](app/README.md) for the full documentation: the career
progression, the adaptive difficulty engine, the five mini-games and the A4
worksheet printing centre.
