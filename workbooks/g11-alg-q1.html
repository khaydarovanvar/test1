Increments, and the problem of the tangent

The step across, the step up, and the ratio between them — the one quotient the whole of this term is built on.

Lessons 1–2 · Algebra and Calculus 11, §1.1 · Pure Mathematics 1, 7.1 · 45 questions

KEY WORDS
  • increment of the argument
  • increment of the function
  • difference quotient
  • average rate of change
  • secant
  • tangent
  • gradient
  • limiting position
  • instantaneous rate
REMEMBER
  1. Increment of the argument Δx = x2 − x1; increment of the function Δy = f(x1 + Δx) − f(x1).
  2. The quotient ΔyΔx is the gradient of the secant through the two points.
  3. Average rate of change on [a, b] is f(b) − f(a)b − a.
  4. The tangent is the limiting position of the secant as Δx → 0.
  5. Simplify ΔyΔx completely before letting Δx → 0 — the h in the denominator must cancel.

The limit of a function

What a function does near a point, not at it — and the four techniques that get past the form 00.

Lessons 3–4 · Algebra and Calculus 11, §1.2 · Pure Mathematics 1, 7.2 · 45 questions

KEY WORDS
  • limit
  • tends to
  • one-sided limit
  • indeterminate form
  • conjugate expression
  • continuous function
  • point of discontinuity
  • removable discontinuity
  • infinity
REMEMBER
  1. limx→a f(x) = L describes f near a. The value f(a) itself is irrelevant, and need not exist.
  2. The limit exists only when the two one-sided limits agree.
  3. Substitute first. If it gives a number, that number is the limit.
  4. The form 00 means a common factor is hiding: factorise and cancel, or multiply by the conjugate.
  5. For x → ∞ in a rational function, divide every term by the highest power of x.

The derivative of a function

The limit of the difference quotient — differentiation from first principles, and what the answer measures.

Lessons 5–6 · Algebra and Calculus 11, §1.3 · Pure Mathematics 1, 7.1–7.2 · 45 questions

KEY WORDS
  • derivative
  • differentiation
  • from first principles
  • gradient function
  • differentiable
  • instantaneous velocity
  • Leibniz notation
  • corner point
  • rate of change
REMEMBER
  1. f′(x) = limh→0 f(x + h) − f(x)h.
  2. Four steps: write f(x + h); form Δy and simplify; divide by h; let h → 0.
  3. f′(a) is the gradient of the tangent at x = a, and the instantaneous rate of change there.
  4. f′(x), y′ and dydx all name the same thing.
  5. Differentiable at a point ⇒ continuous there. The converse is false: |x| at x = 0.

The rules of differentiation

The table of derivatives, and the four rules that differentiate anything built out of it.

Lessons 7–9 · Algebra and Calculus 11, §1.4 · Pure Mathematics 1, 7.3 · 45 questions

KEY WORDS
  • power rule
  • constant multiple rule
  • sum rule
  • product rule
  • quotient rule
  • fractional index
  • negative index
  • simplify first
  • second derivative
REMEMBER
  1. (xn)′ = nxn−1, for every real n — whole, negative or fractional.
  2. (cf)′ = cf′ and (u ± v)′ = u′ ± v′: constants come out, sums split up.
  3. Product rule: (uv)′ = u′v + uv′.
  4. Quotient rule: (uv)′ = u′v − uv′v2 — the order in the numerator matters.
  5. Rewrite roots and reciprocals as powers first. There is no product or quotient rule you need if the expression simplifies.

The derivative of a composite function

The chain rule — differentiate the outside, then multiply by the derivative of the inside.

Lessons 10–12 · Algebra and Calculus 11, §1.5 · Pure Mathematics 1, 7.4 · Pure Mathematics 2, 4.4 · 45 questions

KEY WORDS
  • chain rule
  • composite function
  • inner function
  • outer function
  • intermediate variable
  • bracket power
  • substitution u
  • connected rates
REMEMBER
  1. dydx = dydu · dudx — the intermediate variable cancels like a fraction.
  2. [f(g(x))]′ = f′(g(x)) · g′(x): outer derivative at the inner value, times the inner derivative.
  3. [(ax + b)n]′ = na(ax + b)n−1. The factor a is the mark most often lost.
  4. Name the inner function before you write anything else.
  5. Chains combine with the product and quotient rules: deal with the outer structure first.

REMEMBER

1 nan−1

By the binomial theorem (a + h)n = an + nan−1h + n(n−1)2an−2h2 + … + hn. Subtracting an and dividing by h leaves nan−1 + n(n−1)2an−2h + … + hn−1. Every term after the first carries a factor h, so as h → 0 they all vanish and the quotient tends to nan−1.

2 x = 2

The secant gradient is 9 − 13 − 1 = 4. The tangent gradient at x = c is 2c, so 2c = 4 and c = 2, which lies in (1, 3). This is the mean value theorem in its simplest case.

3 True for every quadratic

Let f(x) = px2 + qx + r. Then f(b) − f(a) = p(b2 − a2) + q(b − a) = (b − a)[p(a + b) + q], so the secant gradient is p(a + b) + q. The tangent gradient at x = c is 2pc + q, and 2pc + q = p(a + b) + q gives c = a + b2.

4 c = √ab

The secant gradient is −1ab from Challenge 6. The tangent gradient at x = c is −1c2, so c2 = ab and c = √ab, the geometric mean. It lies between a and b because a < √ab < b whenever 0 < a < b.

The left side is the distance from x to 1 plus the distance from x to 3. Those points are 2 apart, so for any x between them the two distances already add to exactly 2. Outside the interval the sum is larger. The solution set is the whole closed interval [1, 3] — infinitely many solutions.

2 No solution

The smallest the sum of the two distances can be is the gap between the points, which is 2. Since 1 < 2, no point of the line is close enough to both. Algebraically, each of the three cases leads to a false statement or to a root outside its own interval.

3 x = −1 or x = 5

The gap is 2, so 6 − 2 = 4 must be shared equally outside the interval, giving 2 beyond each end: x = 1 − 2 = −1 or x = 3 + 2 = 5. Checking x = 5: 4 + 2 = 6. ✓

4 Proved

For any real t, −|t| ≤ t ≤ |t|. Adding the two statements for a and b gives −(|a| + |b|) ≤ a + b ≤ |a| + |b|, which is exactly |a + b| ≤ |a| + |b|. Equality holds only when a and b have the same sign, or one is zero.

5 Proved

Write a = (a − b) + b and apply the triangle inequality: |a| ≤ |a − b| + |b|, so |a| − |b| ≤ |a − b|. Swapping a and b gives |b| − |a| ≤ |b − a| = |a − b|. The modulus of a number is at most k exactly when both it and its negative are, so ||a| − |b|| ≤ |a − b|.

6 f′(x) = 2|x|; f″(0) does not exist

As in Topic 3, f′(x) = 2|x| for every x, including x = 0. But 2|x| is itself a modulus function, with a corner at the origin: its one-sided derivatives there are 2 and −2. So f″(0) does not exist. A function can be once differentiable everywhere without being twice differentiable.

7 x ≤ 1 or x ≥ 4

|t| = t holds exactly when t ≥ 0. So the equation says x2 − 5x + 4 ≥ 0, that is (x − 1)(x − 4) ≥ 0. A product of two factors is non-negative when both are non-negative or both non-positive, giving x ≤ 1 or x ≥ 4.

8 2, attained at x = 2

The outer two terms add to at least 2, the gap between 1 and 3, with equality for every x in [1, 3]. Inside that interval the remaining term |x − 2| is least when x = 2, where it is 0. So the minimum is 2 + 0 = 2 at x = 2 — the median of the three points, which is the general rule for an odd number of terms.

9 Constant, equal to 2, on 0 ≤ x ≤ 2

For x < 0 the sum is −x + (2 − x) = 2 − 2x, falling. For 0 ≤ x ≤ 2 it is x + (2 − x) = 2, constant. For x > 2 it is x + (x − 2) = 2x − 2, rising. The graph is a flat-bottomed valley with a horizontal floor of length 2, not a single vertex.

10 x ≥ 1

The statement |t| = t holds exactly when t ≥ 0, so x − 1 ≥ 0 and x ≥ 1. Every such x works, so the answer is a half-line, not a point.

11 −2 ≤ x ≤ 2

The left side is the distance from x to 1 plus the distance to −1. Those points are 2 apart, so the sum is 2 throughout [−1, 1] and grows by 2 for each unit outside. To reach 4 requires 1 unit beyond either end, so the sum is at most 4 exactly on [−2, 2].

12 √x2 = |x|

The radical sign denotes the non-negative square root. Squaring destroys the sign of x, and the root cannot restore it, so the output is always non-negative. For x = −3, √(−3)2 = √9 = 3 = |−3|, not −3. The identity √x2 = x is true only for x ≥ 0.

13 a = −2 or a = 4

Substituting gives |1 − a| = 3, so 1 − a = 3 or 1 − a = −3, that is a = −2 or a = 4. Read as distance: a must be 3 away from 1, and there are two such points, one on each side.

14 Continuous, not differentiable

Continuity: both one-sided limits at 0 equal 0, which is |0|, so the function is continuous. Differentiability: the quotient |h|h is 1 for h > 0 and −1 for h < 0, so the one-sided derivatives are 1 and −1. They disagree, so no derivative exists. This is the standard example showing continuity does not imply differentiability.
