REMEMBER
  1. (sin x)′ = cos x and (cos x)′ = −sin x — the minus sign on the cosine is the mark most often lost.
  2. (ex)′ = ex: the one function that is its own derivative. (ln x)′ = 1x.
  3. Radians, always. In degrees (sin x°)′ = π180cos x° instead.
  4. Chain rule: differentiate the outside, then multiply by the derivative of the inside.
  5. ddxln f(x) = f′(x)f(x) — worth knowing on sight.

Why radians, and not degrees

Every formula below is false in degrees. An angle of x degrees is πx180 radians, so sin x° = sinπx180, and the chain rule drags that constant through: (sin x°)′ = π180cos x° ≈ 0.01745 cos x°.

Radians are the measure in which the constant comes out as exactly 1. That is the whole reason calculus insists on them.

Where (sin x)′ = cos x comes from

Start from the definition and expand with the addition formula.

  1. sin(x + h) − sin xhthe difference quotient
  2. = sin x · cos h + cos x · sin h − sin xhaddition formula for sin(x + h)
  3. = cos x · sin hh − sin x · 1 − cos hhsplit, and group the two standard limits
  4. → cos x · 1 − sin x · 0 = cos xlet h → 0

Why e is the base that works

For any base, (ax)′ = ax · limh→0ah − 1h. That limit is a constant depending on a, and it equals ln a. So (ax)′ = ax ln a, and the constant is 1 — the function reproducing itself exactly — only when a = e.

The logarithm follows by reversing it: if y = ln x then ey = x, and differentiating both sides gives eydydx = 1, so dydx = 1ey = 1x.

Note (ln|x|)′ = 1x as well, which is what lets 1x be integrated for negative x.

Worked example 1 — a product: y = x2 ln x

  1. u = x2, so u′ = 2xname the first part
  2. v = ln x, so v′ = 1xname the second
  3. y′ = 2x · ln x + x2 · 1xapply u′v + uv′
  4. y′ = 2x ln x + x = x(2 ln x + 1)simplify, then factorise

Worked example 2 — a quotient: y = sin xx

  1. u = sin x, so u′ = cos xthe numerator
  2. v = x, so v′ = 1the denominator
  3. y′ = cos x · x − sin x · 1x2apply u′v − uv′v2 — keep the order
  4. y′ = x cos x − sin xx2tidy the numerator

The five mistakes to watch for

1. Working in degrees. 2. Losing the minus sign on (cos x)′. 3. Reading sin2x as sin(x2). 4. Forgetting the inner derivative — writing (sin 3x)′ = cos 3x instead of 3cos 3x. 5. Treating ln(x3 + 1) as if the chain rule did not apply: it is 3x2x3 + 1, not 1x3 + 1.

Every one of these can be caught by substituting a number into the original and into the derivative and comparing with a numerical gradient.

1 2x cos(x2)

Chain rule with inner function x2. The outer derivative is cos(x2), the inner is 2x, so the answer is 2x cos(x2). Note this is not sin2x.

2 2 sin x cos x = sin 2x

Here the outer function is the square, so the derivative is 2sin x times the derivative of sin x, giving 2 sin x cos x. The double-angle identity tidies it to sin 2x.

3 sin x + x cos x

A product: u = x with u′ = 1, and v = sin x with v′ = cos x. Then u′v + uv′ = sin x + x cos x.

4 cos x · esin x

Chain rule: the outer function is the exponential, which reproduces itself, and the inner derivative is cos x. So the answer is cos x · esin x.

5 −tan x

Use ddxln f = f′f with f = cos x: the derivative is −sin xcos x = −tan x.

6 1 − ln xx2

Quotient rule with u = ln x and v = x: 1x · x − ln x · 1x2 = 1 − ln xx2. It is zero at x = e, which is where ln xx reaches its greatest value.

7 x sec2x − tan xx2

Quotient rule with u = tan x and v = x: sec2x · x − tan x · 1x2. Keep the order in the numerator — reversing it flips the sign.

8 ex(sin x + cos x)

A product of two functions neither of which simplifies: ex sin x + ex cos x, and ex factors out.

9 2xx2 + 1

Again f′f, with f = x2 + 1 and f′ = 2x. The commonest error here is writing 1x2 + 1 and dropping the inner derivative.

10 3sec2(3x + 1)

The outer derivative is sec2(3x + 1) and the inner is 3, giving 3sec2(3x + 1).

Hard · hard

1 11 + cos x

The quotient rule gives cos x(1 + cos x) − sin x(−sin x)(1 + cos x)2 = cos x + cos2x + sin2x(1 + cos x)2. Since cos2x + sin2x = 1 the numerator is 1 + cos x, which cancels one factor below, leaving 11 + cos x.

2 sec x

Using f′f with f = sec x + tan x and f′ = sec x tan x + sec2x = sec x(tan x + sec x). The bracket is f itself, so it cancels and the derivative is sec x. This is why that logarithm is the antiderivative of sec x.

3 −sin x · cos(cos x)

A chain with a trigonometric function inside another. The outer derivative is cos(cos x) and the inner is −sin x, giving −sin x · cos(cos x). Keep the two arguments apart: the outer cosine is evaluated at cos x.

4 xx(1 + ln x)

Neither the power rule nor the exponential rule applies, since both base and index vary. Take logarithms: ln y = x ln x. Differentiating, y′y = ln x + x · 1x = ln x + 1, so y′ = xx(1 + ln x).

5 (sin x)x(ln sin x + x cot x)

Logarithmic differentiation again: ln y = x ln(sin x), so y′y = ln(sin x) + x · cos xsin x = ln(sin x) + x cot x. Multiplying back gives the answer.

6 ex(1 + ex)2

The quotient rule gives ex(1 + ex) − ex · ex(1 + ex)2. The numerator is ex + e2x − e2x = ex. The derivative is positive everywhere, so this function — the logistic curve — always increases.

7 −1e, at x = 1e

dydx = ln x + 1, zero when ln x = −1, that is x = 1e. Then d2ydx2 = 1x > 0, so it is a minimum, of value 1e · (−1) = −1e ≈ −0.368.

8 −2e−x cos x

First, y′ = −e−x sin x + e−x cos x = e−x(cos x − sin x). Differentiating again, y″ = −e−x(cos x − sin x) + e−x(−sin x − cos x) = e−x(−cos x + sin x − sin x − cos x) = −2e−x cos x.

9 Maximum √2 at x = π4; minimum −√2 at x = 5π4

dydx = cos x − sin x = 0 gives tan x = 1, so x = π4 or 5π4. Then d2ydx2 = −sin x − cos x, which is −√2 < 0 at π4 and √2 > 0 at 5π4. The values are ±√2, which also follows from writing y = √2 sin(x + π4).

10 −cosec2x

Write cot x = cos xsin x. The quotient rule gives −sin x · sin x − cos x · cos xsin2x = −(sin2x + cos2x)sin2x = −1sin2x = −cosec2x. The minus sign comes out of the numerator, not from anywhere else.
