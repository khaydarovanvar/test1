Inequalities with one unknown

Solving an inequality is solving an equation with one extra rule — and an answer that is a whole interval, not a number.

Lessons 49–50 · Algebra 8, §15, pp. 85–93 · Cambridge Stage 9 · 4.3 · 45 questions

Key words
  • inequality with one unknown
  • solution of an inequality
  • solution set
  • interval
  • number line
  • equivalent inequalities
  • reverse the sign
  • no solutions
  • every number
Remember
  1. Every step of solving an equation is allowed, with one exception: multiplying or dividing by a negative reverses the sign.
  2. The answer is a set. Write it as an inequality or an interval, and draw it on a number line.
  3. An unknown that cancels leaves either a true statement (every number works) or a false one (none do).
  4. Never multiply by an expression whose sign you do not know — x could be negative.
  5. For a product or a fraction, mark the critical values on a line and test one point in each region.

Before you start — the ideas behind the Beyond problems
Only one rule differs from equations
Every step that solves an equation is allowed, except that multiplying or dividing by a negative reverses the sign. Test one value from your answer to catch it.
Never multiply by an unknown sign
From 1x > 2 you may not multiply by x: it could be negative. Split into cases, or move everything to one side.
Critical values and regions
For a product or a fraction, mark where each factor is zero or undefined, then test one point in each region. The sign alternates between consecutive critical values.
When the unknown cancels
A true statement left behind means every number works; a false one means none do. 3x + 1 > 3x is the first, 2x + 5 < 2x + 3 the second.
Counting integer solutions
Solve first, then count. Watch which ends are included: −2 ≤ x < 4 holds for six integers, not seven or five.

Systems of inequalities. Number intervals

Two conditions at once — the answer is where the two solution sets overlap.

Lessons 51–52 · Algebra 8, §16, pp. 94–104 · Cambridge Stage 9 · 4.3 · 45 questions

Key words
  • system of inequalities
  • intersection
  • number interval
  • segment (closed interval)
  • open interval
  • half-open interval
  • ray (half-line)
  • double inequality
  • empty set
Remember
  1. Solve each inequality separately, then take the overlap on a number line.
  2. Notation: [a, b] includes its ends, (a, b) excludes them, (a, b] does one of each.
  3. No overlap means no solutions — write the empty set, not nothing.
  4. A double inequality such as 1 ≤ 2x + 3 ≤ 9 is one system; do the same thing to all three parts.
  5. For a quadratic or a product, the sign alternates between consecutive roots.

Before you start — the ideas behind the Beyond problems
Overlap, not union
A system asks for both conditions at once, so the answer is the intersection. Draw both on one number line and read off where they overlap.
Interval notation
[a, b] includes its ends, (a, b) excludes them. A square bracket pairs with ≤, a round one with <.
Double inequalities
1 ≤ 2x + 3 ≤ 9 is one system: do the same thing to all three parts, and reverse all of it if you multiply by a negative.
Quadratic inequalities
Factorise, find the roots, then decide between or outside: a positive-leading quadratic is below the axis between its roots.
Empty is an answer
If the two sets do not overlap, say so. x > 3 with x < 1 has no solution, and writing nothing is not the same as writing that.

The modulus of a number

Distance from zero — one idea that turns every modulus equation and inequality into something you can already solve.

Lessons 53–54 · Algebra 8, §17, pp. 105–110 · Cambridge Stage 9 · beyond · 45 questions

Key words
  • modulus (absolute value)
  • distance from zero
  • non-negative
  • two cases
  • opposite numbers
  • equation with a modulus
  • inequality with a modulus
  • solution set
Remember
  1. |x| is the distance from x to 0, so it is never negative.
  2. |x − a| is the distance from x to a — the quickest way to read any modulus question.
  3. |x| = a has two solutions when a > 0, one when a = 0 and none when a < 0.
  4. |x| < a is one interval; |x| > a is two.
  5. With a modulus on both sides, squaring is safe — both sides are non-negative.

Before you start — the ideas behind the Beyond problems
Modulus is distance
|x − a| is the distance from x to a. Read every modulus question that way and most of them stop needing algebra.
Less gives one interval, greater gives two
|x| < a is −a < x < a; |x| > a is two rays. Mixing these up is the commonest error in the topic.
Two cases, or square
With a modulus on one side, split into the two cases and check each answer. With a modulus on both sides, squaring is safe — both sides are non-negative.
Sums of distances
|x − 1| + |x − 3| is the total distance to 1 and 3. It equals the gap between them on the whole segment, and exceeds it outside.
The right side must be non-negative
In |x − 2| = 2x the right side forces x ≥ 0 before any case work begins — that is what rejects the spurious root.

Approximate values and error

Every measurement is approximate — this topic says by how much, and how to write it honestly.

Lessons 55–57 · Algebra 8, §§18–19, pp. 111–117 · Cambridge Stage 9 · 3.4 · 45 questions

Key words
  • exact value
  • approximate value
  • absolute error
  • relative error
  • round
  • decimal place
  • significant figures
  • accuracy
  • measurement
Remember
  1. Absolute error is |exact − approximate|; relative error is that divided by the exact value, usually as a percentage.
  2. Rounding to the nearest unit gives an absolute error of at most half a unit.
  3. Round once, from the original. Rounding twice can push a value the wrong way.
  4. Relative error, not absolute, decides whether a measurement is good enough.
  5. Leading zeros are not significant; trailing zeros after the point are.

Before you start — the ideas behind the Beyond problems
Half a unit
Rounding to the nearest unit gives an absolute error of at most half a unit. That single sentence generates every bound in this topic.
Absolute against relative
Absolute error is a size; relative error is that divided by the value. An error of 1 is nothing in 500 and ruinous in 5.
Round once
Rounding to 2 d.p. and then to 1 can lift a value over the halfway line. 2.449 → 2.45 → 2.5, but directly it is 2.4.
Errors add for products
Relative errors add when quantities multiply, so three measurements each good to 1% give a product good to about 3%.
Powers multiply the error
Squaring doubles the relative error, cubing triples it. A side known to 1% gives an area known to about 2%.

Upper and lower bounds

A rounded measurement is an interval, not a number — and the interval spreads as soon as you calculate with it.

Lessons 58–59 · Algebra 8, Chapter II revision, pp. 118–121 · Cambridge Stage 9 · 3.4 · 45 questions

Key words
  • upper bound
  • lower bound
  • rounded to
  • nearest
  • half a unit
  • sum
  • difference
  • product
  • quotient
Remember
  1. Rounded to the nearest unit means half a unit either way: a − ½ ≤ x < a + ½.
  2. Sum: add the lower bounds for the lower, the upper for the upper.
  3. Difference: lower minus upper gives the lower bound, and the reverse.
  4. Quotient: largest over smallest for the upper bound, smallest over largest for the lower.
  5. Keep bounds unrounded until the final answer — rounding them throws away the accuracy they exist to record.

Before you start — the ideas behind the Beyond problems
A measurement is an interval
8 to the nearest whole means 7.5 ≤ x < 8.5. Write both bounds before calculating anything.
Which end for which answer
Sum: low with low. Difference: low minus high. Product: low times low. Quotient: low over high. Pairing the wrong ends is the usual slip.
Check the denominator
Before trusting a corner of a range for a fraction, make sure no point of the box makes the denominator zero.
Subtracting near-equal numbers
Two masses of 1.0 kg each to 1 d.p. have a difference somewhere in (−0.1, 0.1) — as wide as the whole uncertainty. Precision is destroyed.
Keep bounds unrounded
Round only the final answer. Rounding a bound first both shifts and shrinks the interval, so it may no longer contain the true value.

2 The multiplier is 1 − x210000
(1 + x/100)(1 − x/100) = 1 − x²/10000, which is below 1 for every x ≠ 0. The order of the two changes makes no difference.
3 (2, 3) and (3, 2)
Substitute y = 5 − x: x² + (5−x)² = 13 gives 2x² − 10x + 12 = 0, so x = 2 or 3. A linear equation with a quadratic one needs substitution, not elimination.
4 (2, 4) and (4, 2)
x and y are the roots of t² − 6t + 8 = 0, that is 2 and 4. Vieta turns a symmetric pair of equations into one quadratic.
5 y = (x2 − 4x + 4) − 1, i.e. y = x2 − 4x + 3
Write y = a(x−2)² − 1. At (0, 3): 4a − 1 = 3, so a = 1 and y = (x−2)² − 1 = x² − 4x + 3.
6 −b2a
Completing the square: a(x + b/2a)² + (c − b²/4a). The squared term is least (or greatest) when x = −b/2a, and that is the axis of symmetry.
7 k = ±4
Touching once means a repeated root, so D = k² − 16 = 0 and k = ±4. The curve then has its vertex on the axis.
8 Infinitely many — the same line.
The second equation is twice the first, so every point of the line 2x + y = 7 is a solution. Two equations are not always two conditions.
9 No solution.
Halving the second gives x + y = 4, contradicting x + y = 3. The lines are parallel and never meet.
10 None — back to the start.
The multipliers 1.25 and 0.8 are reciprocals, so the price returns exactly. This is the one pair of percentages where the usual loss does not happen — because the percentages differ.
11 −1 < x < 3
The parabola opens upwards and cuts the axis at −1 and 3, so it dips below between them.
12 About 6.7%
(1 − p/100)¹⁰ = 0.5, so 1 − p/100 = 0.5^(1/10) ≈ 0.933 and p ≈ 6.7.
13 (1, 1) — the line is a tangent
x² − 2x + 1 = (x−1)² = 0 has a repeated root, so the line meets the curve at one point and does not cross it.
14 6 and 4
x² − y² = (x+y)(x−y) = 10(x−y) = 20, so x − y = 2. With x + y = 10 the numbers are 6 and 4 — no quadratic needed.
15 Replace x by −b2 ± t
Writing y = (x + b/2)² + (c − b²/4), the value depends only on (x + b/2)², which is unchanged when x + b/2 changes sign. So points equally far either side of x = −b/2 have equal heights.

1 x = 0
Dividing by x assumes x ≠ 0 and so deletes that root. Factorise instead: x(x − 4) = 0.
2 x = ±5
Taking a square root gives both signs. The arithmetic root symbol √25 is 5, but the equation x² = 25 has two solutions.
3 x = 5 ± 32, so 1 and 4
The formula uses √D, not D. Here √9 = 3, giving 4 and 1.
4 No solution — x = 1 is forbidden.
Cancelling the denominator gives 1 = x, but x = 1 makes both sides undefined. Every candidate must be checked against the denominators.
5 x = a or x = a + 2
The discriminant is 4(a+1)² − 4(a²+2a) = 4, so x = (a+1) ± 1.
6 k = −4
Subtracting the two equations gives (k − 3)x + (k − 3) = 0, so either k = 3 or x = −1. At k = 3 the first equation is x² − 3x + 3 = 0 with D = −3, so it has no real root at all. Putting x = −1 into the first gives 1 + 3 + k = 0, so k = −4; then the equations are x² − 3x − 4 = 0 (roots −1, 4) and x² + 4x + 3 = 0 (roots −1, −3), sharing −1.
7 c < 0
The product of the roots is c. A negative product means one root of each sign, and that also forces D = b² − 4c > 0, so the roots are real.
8 15
180/(n−3) − 180/n = 3 gives n² − 3n − 180 = 0, so n = 15.
9 x = 1, −1, 3
Group: x²(x−3) − (x−3) = (x−3)(x²−1) = (x−3)(x−1)(x+1).
10 −3 — it agrees
The product is c/a = −6/2 = −3, whatever b is. Vieta gives the product without solving.
11 a = 0 or a = 4
a = 0 makes it linear with one root; a ≠ 0 needs D = 16 − 4a = 0, so a = 4.
12 12 and 14
x² + (x+2)² = 340 gives 2x² + 4x − 336 = 0, that is x² + 2x − 168 = 0 and x = 12 or −14. Both give valid pairs.
13 x = ±√3 + √52 and ±√3 − √52
With t = x²: t + 1/t = 3 gives t² − 3t + 1 = 0 and t = (3 ± √5)/2. Both are positive, so each gives two values of x — four roots in all.
14 Parity.
If x is even, x² + bx + c is odd + even... more carefully: x² + bx is even when x is even and even when x is odd (x² and bx are both odd, and their sum is even). Adding the odd c leaves an odd number, never 0.
15 k = ±12, ±13, ±15, ±20, ±37
The roots multiply to 36 and add to −k. The factor pairs of 36 — (1,36), (2,18), (3,12), (4,9), (6,6) and their negatives — give the sums 37, 20, 15, 13, 12 and their opposites.
