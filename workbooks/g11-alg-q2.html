UNIT 2 · APPLICATIONS OF THE DERIVATIVE · TOPIC 1

Approximate calculations with the derivative

The tangent standing in for the curve — good enough for a square root, and only over a short step.

Lessons 28–30 · Algebra and Calculus 11, §1.9 · Pure Mathematics 1, 8.4 · Pure Mathematics 2, 6 · 45 questions

KEY WORDS
  • approximation
  • linear approximation
  • small increment
  • differential
  • absolute error
  • relative error
  • percentage error
  • convenient point
  • order of accuracy
REMEMBER
  1. Δy ≈ f′(x) · Δx, so f(x + Δx) ≈ f(x) + f′(x) · Δx.
  2. Choose a convenient point — one where f and f′ are exact, and close to the value wanted.
  3. dy = f′(x)dx is the rise along the tangent; Δy is the rise along the curve. They differ by an amount of order (Δx)2.
  4. Relative error is |Δyy|; percentage error is 100 times it.
  5. A p % error in a length gives about 2p % in an area and 3p % in a volume.

UNIT 2 · APPLICATIONS OF THE DERIVATIVE · TOPIC 2

Modelling with the derivative

A rate in the world, written as a derivative — motion, growth, cost — then read back as an answer with units.

Lessons 31–34 · Algebra and Calculus 11, §1.10 · Pure Mathematics 1, 8.4 · 45 questions

KEY WORDS
  • mathematical model
  • displacement
  • velocity
  • acceleration
  • connected rates
  • marginal cost
  • marginal revenue
  • units of a rate
  • instant of rest
REMEMBER
  1. v = dsdt and a = dvdt = d2sdt2. At rest means v = 0, not s = 0.
  2. Connected rates run through the chain rule: dVdt = dVdr · drdt. Substitute the numbers last.
  3. Displacement is s(t2) − s(t1); distance travelled splits the journey at every instant of rest.
  4. Marginal cost is C′(x) and marginal revenue R′(x); profit is greatest where they are equal.
  5. Every answer carries units, and a negative rate means the quantity is falling.

UNIT 3 · THE INDEFINITE INTEGRAL · TOPIC 4

The antiderivative and the indefinite integral

Differentiation run backwards — a whole family of curves, and the one condition that picks a single member out of it.

Lessons 37–40 · Algebra and Calculus 11, §2.1 · Pure Mathematics 1, 9.1 · 45 questions

KEY WORDS
  • antiderivative
  • indefinite integral
  • constant of integration
  • integrand
  • family of curves
  • initial condition
  • particular solution
  • integration
  • inverse operation
REMEMBER
  1. F is an antiderivative of f if F′ = f. Checking one is always possible: differentiate it.
  2. If F is an antiderivative then so is F + C, and every antiderivative has that form.
  3. ∫f(x)dx = F(x) + C. The + C is part of the answer, not decoration.
  4. The family F + C is a stack of parallel curves; an initial condition picks one out.
  5. There is no product rule and no quotient rule for integration — simplify the integrand first.

UNIT 3 · THE INDEFINITE INTEGRAL · TOPIC 5

The table of integrals and the rules of integration

Every derivative read backwards, the linear substitution that extends them, and the rewriting that has to come first.

Lessons 41–46 · Algebra and Calculus 11, §2.2 · Pure Mathematics 1, 9.2–9.3 · 45 questions

KEY WORDS
  • table of integrals
  • power rule for integration
  • linear substitution
  • integrable form
  • exceptional case
  • term by term
  • natural logarithm
  • reciprocal function
REMEMBER
  1. ∫xndx = xn+1n + 1 + C for n ≠ −1; and ∫dxx = ln|x| + C, the exceptional case.
  2. ∫(ax + b)ndx = (ax + b)n+1a(n + 1) + C — the 1a is the mark most often lost.
  3. ∫sin x dx = −cos x + C and ∫cos x dx = sin x + C: the minus sign sits on the opposite one from differentiation.
  4. Constants come out and sums split term by term. There is no product or quotient rule.
  5. Rewrite first — roots and reciprocals as powers, products expanded, fractions split.

REMEMBER

  2. Linear inner function: divide by a. Anything harder is Quarter III.
  3. Every indefinite integral ends in + C; every initial condition pins it down.
  4. Reversing a second derivative needs two conditions, not one.
  5. Differentiate your answer. It takes seconds and it settles the question.

1 Of order (Δx)2

Expand f(a + h) as a Taylor series: f(a) + f′(a)h + f″(a)2h2 + …. The linear estimate keeps the first two terms, so the error is f″(a)2h2 plus higher powers. Halving the step therefore cuts the error by a factor of about four — which is why the method is good for √101 and poor for √200.

1 They differ by a constant

Let F′ = G′ = f on an interval and put H = F − G. Then H′ = 0 throughout. By the mean value theorem, for any two points a < b there is c between them with H(b) − H(a) = H′(c)(b − a) = 0, so H takes the same value everywhere. Hence F = G + C. The interval matters — see question 3.

2 Correct for every x

Differentiate the proposed answer. From Quarter I, ddx(x|x|) = 2|x|, so ddxx|x|2 = |x|, which is the integrand. Writing it as two cases also works: x22 for x ≥ 0 and −x22 for x < 0, which join smoothly at the origin.

3 f(x) = 1 − 1x for x > 0 and f(x) = −1 − 1x for x < 0

The antiderivative is −1x + C, but the domain is split at 0, so each branch carries its own constant. On x > 0: −1 + C1 = 0 gives C1 = 1. On x < 0: 1 + C2 = 0 gives C2 = −1. "Antiderivatives differ by a constant" holds on an interval, and this domain is not one.

4 At n = −1 the answer is ln|1 + x| + C

11 They coincide

If y1′ = y2′ on an interval then y1 − y2 has zero derivative, so it is a constant k. At x = 1 both equal 3, so k = 0 and y1 ≡ y2. Two members of the same family either coincide or never meet — which is why the curves of y = x2 + C are parallel.

14 Parallel parabolas, all with the same gradient at each x

15 Sums carry over; products do not

7 F is even

Consider G(x) = F(−x). Then G′(x) = −F′(−x) = −f(−x) = f(x), since f is odd. So G and F have the same derivative and differ by a constant; at x = 0 both are 0, so the constant is zero and F(−x) = F(x). For example f = x is odd and F = x22 is even.

10 y = x − sin x

Integrating once, dydx = −cos x + C1, and the condition at x = 0 gives −1 + C1 = 0, so C1 = 1. Integrating again, y = −sin x + x + C2, and y(0) = 0 gives C2 = 0. The curve y = x − sin x is the cycloid’s x-component, and it is increasing everywhere.

15 No elementary antiderivative exists; it is computed numerically or named

Differentiation is an algorithm: every elementary function has an elementary derivative. Integration is a search, and the elementary functions are not closed under it — Liouville proved that no combination of powers, roots, exponentials, logarithms and trigonometric functions differentiates to ex2. In practice the integral is evaluated numerically, or given a name: the closely related ∫e−x2dx is the error function, on which the normal distribution rests.
