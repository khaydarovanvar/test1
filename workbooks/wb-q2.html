The arithmetic root of degree n

Undoing a power: what the n-th root means, when it exists, and the four properties that let you work with it.

Remember
  1. The arithmetic root is the non-negative one: √(x2) = |x|, never x.
  2. An even root needs a non-negative radicand; an odd root takes any sign.
  3. The four properties: √(ab) = √a · √b, √(a/b) = √a / √b, (√a)2 = a, √(a2) = |a|.
  4. Take a factor out by splitting the radicand into a square times the rest.
  5. Rationalise with the conjugate: multiply by √a − √b over itself.

Before you start — the ideas behind the Beyond problems
Denesting a double root
√a + 2√b simplifies when two numbers add to a and multiply to b: then a + 2√b = (√x + √y)2. So 3 + 2√2 = (1 + √2)2.
Conjugates
Multiply by the conjugate to clear a root below the line. For cube roots use a3 − b3 = (a − b)(a2 + ab + b2), so 13√2 − 1 needs 3√4 + 3√2 + 1.
Telescoping surds
1√k + √k + 1 = √k + 1 − √k — rationalising turns a sum of fractions into a collapsing chain.
Compare by squaring
Both sides positive, so squaring decides. √7 + √5 beats √10 + √2 because 2√35 > 2√20.
Trap the value between squares
n2 < n2 + n < (n + 1)2, so √n2 + n lies strictly between two consecutive whole numbers and is never one itself.

Before you start — the ideas behind the Beyond problems
The definition does the work
a > b means a − b > 0. Every comparison, however awkward, is the sign of one difference.
Sum of squares
Write the difference as a sum of squares and the sign is settled: 2(a2 + b2 + c2 − ab − bc − ca) = (a − b)2 + (b − c)2 + (c − a)2.
AM ≥ GM
a + b2 ≥ √ab because the difference is (√a − √b)22. For three numbers the same follows from a3 + b3 + c3 ≥ 3abc.
Compare by squaring
Only when both sides are non-negative. Then squaring clears roots without disturbing the order.
The workhorse
a2 + b2 + c2 ≥ ab + bc + ca and its cousin (a + b + c)2 ≥ 3(ab + bc + ca) settle a surprising share of competition inequalities.

Only same-direction addition is valid. To handle a difference, turn it into a sum: a − c = a + (−c), and reverse the bounds of c first.

10 Equality when a = b = c
Add 1 to each term: the sum becomes (a+b+c)(1/(b+c) + 1/(c+a) + 1/(a+b)). By the (x+y+z)(1/x+1/y+1/z) ≥ 9 result applied to the three denominators, whose total is 2(a+b+c), this is at least 9/2. Subtracting the 3 we added leaves 3/2. This is Nesbitt's inequality.

12 Square both sides.
